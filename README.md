# Calculadora Flutter

Aplicativo de calculadora desenvolvido com Flutter.

## Demonstração

![Captura da calculadora](meu_app/imgs/Captura%20de%20tela%202026-09-29%20124739.png)

## Pré-requisitos

- Flutter instalado e configurado
- Dart incluído na instalação do Flutter
- Um dispositivo conectado, emulador ou navegador compatível

Verifique a instalação com:

```bash
flutter doctor
```

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Marcelo689/Calculadora_flutter.git
cd Calculadora_flutter/meu_app
```

2. Instale as dependências:

```bash
flutter pub get
```

3. Liste os dispositivos disponíveis:

```bash
flutter devices
```

4. Execute o projeto:

```bash
flutter run
```

Para executar diretamente no Chrome:

```bash
flutter run -d chrome
```

## Testes

Execute os testes com:

```bash
flutter test
```

## Estrutura principal

- `meu_app/lib`: código-fonte da aplicação
- `meu_app/test`: testes automatizados
- `meu_app/imgs`: imagens usadas na documentação
- `meu_app/pubspec.yaml`: dependências e configuração do projeto
